# Компаньон 🍺

**Не сиди один. Компания найдётся.**

Приложение, которое помогает найти компанию для живой встречи — выпить пива, выпить кофе, поиграть в настолки, просто поговорить. Главный принцип: **нашёл → договорился → встретился → убрал телефон → разговариваешь.**

---

## Что это

Backend для мобильного приложения «Компаньон». Позволяет:

- 📝 регистрироваться (18+);
- 🔐 входить по JWT-токену;
- 👤 редактировать профиль (имя, город, интересы, языки, аватар);
- 🗺️ добавлять заведения (бары, кафе, парки);
- 🍻 создавать встречи (формат, время, место, участники);
- 📍 искать встречи рядом (фильтр по расстоянию — Haversine);
- 🤝 присоединяться и выходить из встреч;
- ⭐ отслеживать репутацию (`meetings_count`);
- 🌍 поддержка 8 языков интерфейса (RU, DE, EN, FR, UK, TR, AR, IT).

## Стек технологий

| Слой | Технология |
|---|---|
| Язык | Python 3.12 |
| Фреймворк | FastAPI |
| Сервер | Uvicorn |
| База данных | PostgreSQL 16 (в Docker) |
| ORM | SQLAlchemy 2.x |
| Миграции | Alembic |
| Аутентификация | JWT (python-jose) + bcrypt (passlib) |
| Валидация | Pydantic 2.x |
| i18n | JSON-файлы + собственный модуль |
| Хостинг БД | Docker Compose |
